A program that writes the funniest possible one-line famous last words — a tombstone epitaph of at most 150 characters — to `/output/entry.txt`, for make.fun's "Famous Last Words: The Funniest Epitaph" bounty. The line was chosen by duelling eight original drafts pairwise against the judge's own criteria and submitting only the duel winner.

## Run it

```sh
python3 main.py
```
